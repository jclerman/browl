{# An entity a page mentions (`browl.links.EntityLink`): a link to its page, labeled with its display name, or text if it has none. The name is isolated from the text around it, since labels can hold bidirectional overrides. #} {% macro entity_link(link) -%} {% if link.href is not none %}{{ link.name }} {%- else %}{{ link.name }}{% endif %} {%- endmacro %} {# An IRI a page mentions, from `links` (IRI → `browl.links.EntityLink`), by the name `browl.overview.shown_name` gives it: a link to its page if it has one; else text, its bidirectional-text controls encoded, cut short if long. #} {% macro named_iri(iri, links, text=none) -%} {%- set link = links.get(iri) -%} {%- if link is not none and link.href is not none %}{{ entity_link(link) }} {%- else %}{{ shown_name(iri, links, text) | bidi_encoded | cut_text(MAX_IRI_CHARS) }}{% endif -%} {%- endmacro %} {# The name `named_iri` shows for an IRI, as text alone, not a link: for text screen readers read but the page doesn't show (`.visually-hidden`), which shouldn't hold a link to tab to. #} {% macro named_text(iri, links, text=none) -%} {%- set link = links.get(iri) -%} {%- if link is not none and link.href is not none %}{{ link.name }} {%- else %}{{ shown_name(iri, links, text) | bidi_encoded | cut_text(MAX_IRI_CHARS) }}{% endif -%} {%- endmacro %} {# An IRI with no page here: an `http` or `https` one as a link to itself (DESIGN.md §2.9), without a referrer, unless it's too long to show whole, as a cut one could hide where it goes; any other as text, cut short if long.
